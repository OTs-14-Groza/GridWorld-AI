# GridWorld AI

My first AI project, built using Python.

## Goal
Build an AI agent that learns to navigate a grid
environment using reinforcement learning.

## Current Features
- 4x4 grid environment
- Start point, goal, and obstacles
- Movement in four directions
- Boundary and obstacle detection
